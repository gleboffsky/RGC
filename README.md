# RGC

**Win32 GDI graphics editor** — draws primitives and edits their geometry.

## Features

- Primitives: arc, ellipse
- Move, scale, change radius and position
- Control panel with live parameters
- Pure Win32 / GDI, no frameworks

## Stack

C++17, Win32 API, GDI, Visual Studio, Windows.

## Build

Open `RGC.sln`, build and run `RGC.exe`.
